## Граница проверки

Браузерный прогон не заменяет проверку Windows, реальных системных диалогов, флешки, физического сна/блокировки ОС или подписанного установщика. Сценарии нескольких независимых баз, смены доступа, восстановления, удалений и конфликтов проверяются отдельными интеграционными тестами. Electron запускается отдельным скрытым сценарием с заранее заданными ответами диалогов.

Повторение:

```sh
npm run build
node e2e/run.cjs --production
```

Для проверки текущих исходников доступен `node e2e/run.cjs`; он использует Next dev. Каждый сценарий выводит собственную папку артефактов. В production sandbox копируются только ресурсы программы и SQL-миграции; данные, .env и файлы базы исключены.
