## Интеграция и code review

Работа агентов проверена и сведена в общие реестры полей, права доступа, методы хранения, файловый мост и протокол синхронизации. Родительский исполнитель проверил совместные сценарии, а отдельные агенты проверили импорт, прежние функции, синхронизацию доступа и настольную упаковку.

Исправлены выявленные ошибки: небезопасное автоматическое сопоставление инициалов; замена конфликтующих полей без решения; ложные конфликты после принятия общей истории; различающийся порядок свойств контейнера ключа при расчёте отпечатка; подтверждение восстановления для незашифрованной базы; перенаправление loopback на другой origin; остатки импортного задания после смены роли; первый клик скрытия сканов; старые незащищённые резервные копии при включённом шифровании; потеря стабильных ID экскурсий; блокируемая Electron ссылка скачивания вложений. Из поставки исключены .env, базы, вложения и локальные настройки.

Одному агенту не удалось выполнить отдельный обзор хранения из-за отказа автоматического фильтра инструмента. Эти файлы проверил родительский исполнитель; независимый внешний криптографический аудит не проводился.

## Платформы и пределы приёмки

Windows — основная целевая платформа заказчика. Проверены Windows-имена файлов, преобразование путей в file URL, наличие нативных prebuilds, состав ресурсов и конфигурация NSIS. Произвольный выбор каталога установки выключен; guard до установки и удаления отклоняет пересечение с папкой базы текущего пользователя, включая переданный `/D` и зарегистрированный старый путь. Guard проверен по коду и документации и успешно скомпилирован NSIS 3.0.4.1 на Mac в отдельном синтетическом .nsi. Артефакты — tdb-nsis-syntax-l6enht в временной папке Mac. Это проверка синтаксиса hooks, а не запуск Windows или сборка полного Windows-приложения. Для Windows нужен собственный билд на Windows x64; сборка на Mac не считается Windows-дистрибутивом. Добавлены ручные CI-сценарии [Windows](../.github/workflows/windows-x64.yml) и [Docker](../.github/workflows/docker-web.yml). Они не отправлены в репозиторий и не запускались внешне.

На целевых устройствах остаются приёмка реальных системных диалогов и флешки, установленного Windows-приложения, физической блокировки/сна ОС и обновления уже используемой установки с резервной копией. Подпись Windows, подпись/нотаризация macOS и корпоративные требования к установке не настраивались. Тестовая сборка не объявляется подписанным выпуском.

Проверка npm audit не чистая: 22 предупреждения (10 high, 11 moderate, 1 low, 0 critical) в полном дереве зависимостей, включая транзитивные инструменты разработки/упаковки и офисные библиотеки. Принудительная смена major-версий без проверки совместимости не выполнялась; это отдельное ограничение подготовки выпуска. Audit не доказывает достижимость каждой уязвимости через интерфейс приложения.

Формат хранения и пределы защиты описаны в [STORAGE_DESIGN.md](STORAGE_DESIGN.md). Контракты импорта и синхронизации — в [модуле импорта](../lib/batch-import/README.md) и [модуле синхронизации](../lib/sync/README.md).
